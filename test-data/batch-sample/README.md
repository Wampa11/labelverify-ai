# Batch sample data (synthetic)

These fixtures are **synthetic demo materials** for evaluating Batch Review.
They are **not** approved TTB labels and are **not** official COLA records.

## Manifest

Download a sample CSV from the running API:

`GET /api/v1/batches/sample-manifest`

Or use `sample-manifest.csv` in this folder.

Columns:

`filename,brand_name,class_type,alcohol_content,net_contents`

## Images

JPEG fixtures generated by `backend/scripts/generate_demo_labels.py`:

| File | Expected tendency |
|------|-------------------|
| `old-tom-001.jpg` | Match → PASS (when OCR reads cleanly) |
| `stones-throw-002.jpg` | Match → PASS |
| `demo-review-003.jpg` | Partial class text → often REVIEW |

Provide JPEG/PNG/WebP files whose basenames match the `filename` column.
